Opening it on a Mac (for now)

This early build is not yet notarised with Apple. Unzip it, move webfaCe Desk to Applications, then right-click it → Open → Open once. From then on it opens normally — the app clears the warning itself on that first run.

Windows: if SmartScreen appears, choose More info → Run anyway. Linux: unzip and run the webfaCe Desk file (needs WebKitGTK, present on Ubuntu desktop).
