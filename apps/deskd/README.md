# deskd — the Desk box agent

Node (no framework) HTTP service on `127.0.0.1:8090` behind Caddy on every Desk box. It owns everything around the harness: sign-in (`auth.js`: owner/phone roles, scrypt, HMAC cookie; Google sign-in through the store's relay), the Business page → `work/AGENTS.md` and brand (`profile.js`), Connections and their step-per-screen wizards (`connections.js`, `wizards.js`; Google via the customer's own OAuth client, WordPress application passwords, webfaCeMEdia via OAuth with a loopback token proxy `webface-oauth.js`), Files + the viewer (`files.js`), Routines page (`routines.js`, mirror written by `@webface/dsh-desk-routines`), Browser page (noVNC `rfb.js` embedded), Web Push (`push.js`), usage metering (`usage.js`), billing state from the store, and the heartbeat to deskapi. `fsx.js` = atomic private writes; use it for every state file.

Routes are listed at the top of `src/index.js`. Owner-only routes are enforced in the phone fence there, not only by Caddy. Every page uses `layout()` from `ui.js`. Env comes from `/srv/desk/desk.env` (see DESK.md). Restart with `systemctl restart deskd`; `node src/cli.js set <user> <email> [password]` manages owner accounts.
