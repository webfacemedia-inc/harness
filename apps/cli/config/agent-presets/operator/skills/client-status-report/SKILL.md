# Client status

- Read the source of truth first (the repo, the deploy state, the calendar, the thread), not a summary.
- Sections: done (with proof), in progress, blocked (on whom, since when), decisions needed from the client, next date.
- Say plainly when something is not done. Do not report a feature as done because a helper exists.
