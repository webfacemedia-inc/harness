name: handoff-doc
description: Operator skill. Use when a piece of work changes hands (to a client, a contractor, or a future session) — what a handoff must contain so nothing is re-learned.
---

# Handoff

- Where things run and how to verify they run (URLs, units, logs).
- What is built, what is switched off on purpose, what is not built.
- The traps already paid for (one line each, with the fix).
- Secrets: where they live (never in the doc).
- The next three actions, in order, with who owns each.
