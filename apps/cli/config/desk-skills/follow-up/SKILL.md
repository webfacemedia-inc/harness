# Follow up

1. Find the thread (`gmail_search`, e.g. `to:<customer> newer_than:14d`). Read it fully.
2. Write a two-line follow-up that references the last message, restates the one open question or offer, and gives an easy next step. After a completed visit: thank them and, if `house-rules.md` allows, ask for a review with the link from the business profile.
3. Draft it in the thread; send only with approval.
