# Draft outreach

- One email per recipient that answers every open item; never split into a burst.
- Links go on descriptive text ("See the preview →"), never pasted raw, never hash routes; when using Gmail, send HTML with real anchors so nothing gets rewritten into tracking wrappers.
- Never invent effort, duration, or savings. Never say "AI" or "generated": the studio writes, designs, builds.
- Preview-first: when you can show the thing (a redesign preview, a demo), lead with it instead of asking for a call.
- Every outreach email is a draft the operator approves; replies land in the studio's reply router, so mention that replying works.
