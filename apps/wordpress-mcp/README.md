# wordpress-mcp — the WordPress connector

MCP server (stdio) over the WordPress REST API with an application password (`WP_URL`, `WP_USER`, `WP_PASSWORD` from the Connections wizard). Ten tools: read pages/posts/media, create and update as drafts, upload media from a public https URL (no private addresses), publish only with `confirm: true`. Wired per box by deskd's Connections page into the managed block of the harness profile patch.
